# Blazor DataGrid - Column Header Customization

This project showcases how to customize the column headers of a [Blazor DataGrid](https://www.syncfusion.com/blazor-components/blazor-datagrid) component. Column header customization is useful when you need to modify the appearance, styling, or content of DataGrid headers to match your application's design requirements.

The sample includes:
- Basic DataGrid setup with sample order data
- Custom CSS styling applied to header cells
- Column configuration with different data types and formats
- Pagination support

## Features

- **Custom Header Styling**: Apply custom fonts, colors, and sizes to column headers
- **Data Formatting**: Display different data types with appropriate formatting (dates, currency)
- **Pagination**: Built-in pagination for handling large datasets
- **Responsive Layout**: Properly sized grid with fixed column widths

## Prerequisites

* [.NET SDK 10.0](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) or later
* [Visual Studio 2022](https://visualstudio.microsoft.com/vs/) or later
* [Visual Studio Code](https://code.visualstudio.com/)

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/SyncfusionExamples/blazor-datagrid-customize-column-header.git
cd blazor-datagrid-customize-column-header
```

### Run with Visual Studio

1. Open the solution file using Visual Studio 2022 or later.
2. Restore the NuGet packages by rebuilding the solution.
3. Build the project to ensure there are no compilation errors.
4. Run the project.

### Run with .NET CLI

```bash
# Restore dependencies
dotnet restore

# Run the project
dotnet run
```
